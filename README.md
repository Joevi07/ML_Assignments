## About This Repository
This repository contains implementations of **Machine Learning lab exercises** performed in SEM-VI.  
Each exercise focuses on a fundamental ML algorithm and its practical implementation using Python.

---

## List of Exercises

### Exercise 1: Linear Regression
**Objective:**  
To implement Linear Regression and understand the relationship between dependent and independent variables.

**Description:**  
- Implemented Linear Regression using Ordinary Least Squares (OLS)  
- Generated predictions for test data  
- Analyzed bias, variance, and overfitting  

**Algorithms Used:**  
- Simple Linear Regression  
- Multiple Linear Regression  

**Evaluation Metrics:**  
- Mean Squared Error (MSE)  
- R² Score  

---

### Exercise 2: k-Nearest Neighbors (KNN)
**Objective:**  
To classify data points using the k-Nearest Neighbors algorithm.

**Description:**  
- Calculated distance between data points  
- Classified samples using majority voting  
- Studied the effect of different values of **k**

**Distance Metric:**  
- Euclidean Distance  

**Key Concepts:**  
- Instance-based learning  
- Bias–Variance tradeoff  

---

### Exercise 3: Naive Bayes Classifier
**Objective:**  
To perform probabilistic classification using Naive Bayes.

**Description:**  
- Calculated prior, likelihood, and posterior probabilities  
- Applied Bayes theorem  
- Classified data based on maximum posterior probability  

**Naive Bayes Types:**  
- Gaussian Naive Bayes  
- Bernoulli Naive Bayes  
- Multinomial Naive Bayes  

**Key Concepts:**  
- Conditional probability  
- Feature independence assumption  

---

### Exercise 4: Model Evaluation / Decision Tree
**Objective:**  
To build a model and evaluate its performance.

**Description:**  
- Trained the model using training data  
- Tested the model using unseen data  
- Evaluated performance using a confusion matrix  

**Evaluation Metrics:**  
- Accuracy  
- Precision  
- Recall  
- F1-score
